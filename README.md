# Cristian Malpica

A cinematic, single-page Product Management portfolio built around one continuous visual idea:

**planet → pupil → perception → product system → evidence → horizon**

The site connects Cristian's systems-thinking worldview with verified professional experience across B2B product lifecycle work, SaaS commercial leadership, customer insight, go-to-market, analytics, operations, and European markets.
